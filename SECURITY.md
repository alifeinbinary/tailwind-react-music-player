# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 5.x     | ✅        |
| < 5.0   | ❌        |

Only the current major line receives security fixes. v4 is end-of-life — please upgrade; see [MIGRATION.md](./MIGRATION.md).

## Reporting a vulnerability

Please report vulnerabilities privately:

- **Preferred:** [GitHub private vulnerability reporting](https://github.com/alifeinbinary/tailwind-react-music-player/security/advisories/new) — open a draft advisory and we'll triage there.
- **Fallback:** email the maintainer at the address in `package.json` (`author` field).

Do **not** open public issues for vulnerabilities, and do not include secrets, tokens, or private infrastructure details in any report — rotate anything you may have already shared.

A reasonable target: acknowledgement within a week, a fix or mitigation plan shortly after depending on severity.
